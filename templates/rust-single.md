# Template: Rust single crate

Use when `Cargo.toml` has `[package]` and no `[workspace]`: one binary, one library, or a crate with both. Use `rust-workspace.md` when the detector reports `layout: "monorepo"`.

## Detection signals
- `primary: "rust"`, `layout: "single"`, `packageManager: "cargo"`.
- `languageVersion.rust` holds `edition`, `rustVersion` (MSRV) and `toolchain`.
- `frameworks` may list `tokio`, `axum`, `actix-web`, `serde`.
- `commands` holds build, test, clippy, fmt and check without `--workspace`. Copy them. If CI uses `-D warnings` or feature flags, use the CI form.
- Library or binary: `src/lib.rs` means library, `src/main.rs` or `[[bin]]` means binary. Say which in the summary line.
- Look for `deny.toml`, `rustfmt.toml`, `clippy.toml`, `benches/`, `build.rs` yourself. The detector does not report them.

## AGENTS.md
- **Commands**: the detector's cargo commands. Add `cargo run -- <args>` for binaries when the README shows usage. Add `cargo nextest run`, `cargo deny check` or `cargo audit` only if config or CI uses them. Add the feature flag combinations CI tests, if any.
- **Repo map**: `src/` modules that matter, `tests/` (integration tests), `examples/`, `benches/`, `build.rs` if present. Keep it to a few lines for a small crate.
- **Conventions worth writing**: error handling style (`thiserror`, `anyhow`, or a custom type) only as the code does it; async runtime if any; where `unsafe` is allowed; feature flag policy for libraries.
- **Version notes**: pull from `knowledge/rust.md` for the detected edition, `rust-version` and key crates. Do not state edition rules or crate APIs from memory.
- **Boundaries**: `Cargo.lock` changes through cargo only. Do not edit `target/` or code generated by `build.rs`. Do not raise `rust-version` or change the edition without asking. For libraries, changes to public items are API changes. Never read or write `.env*`.

## CLAUDE.md
`@AGENTS.md` on the first line. Nothing else unless the user has Claude-only lines.

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "permissions": {
    "allow": [
      "Bash(cargo build *)",
      "Bash(cargo test *)",
      "Bash(cargo check *)",
      "Bash(cargo clippy *)",
      "Bash(cargo fmt *)",
      "Bash(cargo doc *)",
      "Bash(git add *)",
      "Bash(git commit *)"
    ],
    "ask": ["Bash(git push *)", "Bash(cargo add *)", "Bash(cargo install *)"],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(git push --force *)",
      "Bash(git push -f *)",
      "Bash(git reset --hard *)",
      "Bash(cargo publish *)",
      "Bash(cargo yank *)",
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./**/*.pem)"
    ]
  }
}
```
- Add `Bash(cargo run *)` for binary crates.
- Add `Bash(cargo nextest *)`, `Bash(cargo deny *)` or `Bash(cargo audit)` only when config or CI use exists.
- `Read(./.env.*)` also blocks `.env.example`. When the detector's `env.files` lists an example file, deny the real env files by name instead (for example `Read(./.env.local)`, `Read(./.env.production)`) so the example stays readable.

## Formatter hook (optional)
Only when the user says yes. Pass the detected edition because standalone `rustfmt` defaults to an old one. Needs `jq`.
```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.file_path | select(endswith(\".rs\"))' | xargs -r rustfmt --edition <edition>"
          }
        ]
      }
    ]
  }
}
```
Fill `<edition>` from `languageVersion.rust.edition`. Without `jq`, use the command `cargo fmt`. It reads no stdin and takes the edition from `Cargo.toml`.

## Path-scoped rules
Default: none. A single crate is covered by AGENTS.md. Generate one only when:
- `tests/**` has non-obvious conventions (snapshot review, fixtures, deterministic seeds).
- The crate has FFI or `unsafe` modules with safety requirements: scope the rule to those files.
- `benches/**` must stay deterministic.
Mirror rules with `node "${CLAUDE_SKILL_DIR}/scripts/sync-rules.mjs" --targets <tools>` if the user picked other agents.

## Reviewer subagent
These are candidate checks, not defaults. Keep a line only when a repo fact backs it (lint or type config, a documented rule, a hard rule, a detected version), and grep the repo first: if the code already uses a pattern on purpose, drop the line or scope it with the exception.

Generate only when the crate is more than a small tool. `.claude/agents/rust-reviewer.md`, frontmatter `name: rust-reviewer`, `description: Reviews Rust changes for panics, unsafe without justification, async mistakes and API breaks. Use after editing .rs files.`, `tools: Read, Grep, Glob`.
1. No `unwrap()` or `expect()` in library code paths or request handlers. Tests and clearly infallible cases are fine with a message.
2. Every `unsafe` block has a `// SAFETY:` comment stating the invariant.
3. Async: no blocking calls on the runtime. No `std::sync::Mutex` guard held across `.await`.
4. Errors keep their source. Libraries return typed errors, not `String`.
5. Libraries: changed public signatures are flagged. Feature flags stay additive.
6. Lossy `as` casts, and unseeded randomness where output must be reproducible.
7. Tests: no `#[ignore]` without a reason, new behavior has a test, doc examples compile.

## Skills
- `release`: when `Cargo.toml` has a version and a changelog exists. Bump, update changelog, run build, test and clippy, tag. Read any release script or workflow first and match it. Do not add `cargo publish` unless the repo already automates it.
- Nothing else until a real workflow shows up.

## .worktreeinclude
List only entries in `env.gitignored` (`.env`, `.env.local`, `.claude/settings.local.json`, `CLAUDE.local.md`, `.mcp.json`). Do not list `target/`. Skip the file when the list is empty.

## What NOT to generate
- No rules directory by default.
- No `output-styles/`, `commands/` or `agent-memory/`.
- No `cargo audit` or `cargo deny` commands without their config.
- No `Bash(*)`, no `defaultMode` of `auto` or `bypassPermissions`.
